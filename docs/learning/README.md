# Bài học Phase 1

15 bài, mỗi bài một ngày học 6 giờ. Ngày 1–12 đã đạt. Ngày 13 trở đi viết theo cấu trúc mười phần ở dưới. Ngày 1–12 giữ nguyên vì đã khép và mục báo cáo đang ghi kết quả review.

## Cách đọc từ Ngày 13

| Phần | Nội dung |
| --- | --- |
| 1. Mục tiêu | Hôm nay xây dựng tính năng gì |
| 2. Kiến thức nền | Khái niệm cần hiểu trước khi gõ |
| 3. Luồng hoạt động | Một request thật đi qua những chỗ nào |
| 4. Phân tích thiết kế | Vì sao làm cách này |
| 5. Hướng dẫn thực hành | Từng file, đầu vào, việc làm, đầu ra |
| 6. Giải thích code | Đoạn vừa gõ giải quyết việc gì |
| 7. Kiểm thử | Lệnh, kết quả đúng, cách nhìn khi sai |
| 8. Bài tập | Phần bạn tự làm để biết mình hiểu |
| 9. Checklist | Điều kiện xong ngày |
| 10. Báo cáo | Kết quả và phần còn tồn tại |

Ba vai:

- **Bạn tự code** các file trong phần 5. Không đưa cả file cho Cursor điền hộ.
- **Cursor** giải thích khái niệm, chỉ file, review khi bạn gửi `review`. Cursor chỉ sửa file khi bạn nói «hãy code» hoặc chỉ đúng một lỗi cần sửa.
- **Bạn review** kết quả phần 7 trước khi nhờ Cursor tick checklist.

Khi mentor review: tick mục đạt trong phần 9, điền phần 10, liệt kê phần chưa xong. Trống nếu không còn.
